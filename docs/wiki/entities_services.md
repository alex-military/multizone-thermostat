# Entities Created & Exposed Services

A complete reference of all entities automatically generated by **Multizone Thermostat** and services available for scripts and automations.

---

| `switch.master_control_allow_split_cooling` | Switch | `on` / `off` | <span class="badge-beta">BETA</span> Global toggle to permit or lock Split AC cooling. |
| `switch.master_control_anti_seize_summer_protection` | Switch | `on` / `off` | Enables summer anti-seize valve exercise. |
| `switch.master_control_anti_frost_protection` | Switch | `on` / `off` | Emergency frost protection toggle. |
| `switch.time_geofencing_geofencing` | Switch | `on` / `off` | Automated transition to Away preset on departure. |
| `switch.time_geofencing_auto_night_mode` | Switch | `on` / `off` | Automated clock-based transition to Sleep preset. |
| `select.master_control_heat_source_priority` | Select | `auto`, `hybrid`, `combined`, `electric_only`, `gas_only` | <span class="badge-beta">BETA</span> Arbitrates between gas boiler and heat pump / splits. |
| `select.master_control_master_operation_mode` | Select | `heat`, `cool` | <span class="badge-beta">BETA</span> Master seasonal switch between Heating and Cooling. |
| `select.master_control_global_preset` | Select | `manual`, `eco`, `comfort`, `sleep`, `away` | Global household temperature preset selector. |
| `select.master_control_demand_strategy` | Select | `max`, `weighted_average`, `sum_capped` | Aggregation formula for central heating plant demand. |
| `number.master_control_min_cycle_on` | Number | 1 – 30 min (default: 5) | Minimum continuous burner run time. |
| `number.master_control_min_cycle_off` | Number | 1 – 30 min (default: 5) | Minimum rest period before burner restart. |

## 3. Exposed Home Assistant Services

### `multizone_thermostat.set_master_operation_mode`
<span class="badge-beta">BETA</span>

Switches whole-house operation between Heating and Cooling:

```yaml
service: multizone_thermostat.set_master_operation_mode
data:
  operation_mode: cool # 'heat' or 'cool'
```

---

### `multizone_thermostat.set_smart_return`
Schedules an intelligent arrival time with staggered preheating based on thermal inertia:

```yaml
service: multizone_thermostat.set_smart_return
data:
  arrival_time: "18:30" # "HH:MM" or ISO datetime
  preset: comfort
  zones:
    - climate.multizone_thermostat_living
    - climate.multizone_thermostat_bedroom
```

---

### `multizone_thermostat.cancel_smart_return`
Cancels any active Smart Return schedule:

```yaml
service: multizone_thermostat.cancel_smart_return
```

---

### `multizone_thermostat.activate_schedule_profile`
Activates a weekly schedule profile with optional auto-revert timeout:

```yaml
service: multizone_thermostat.activate_schedule_profile
data:
  profile_id: smart_working
  expires_at: "2026-11-15T19:00:00"
  fallback_profile: standard
```

---

### `multizone_thermostat.clear_zone_override`
Clears temporary manual setpoint overrides, restoring scheduled presets:

```yaml
service: multizone_thermostat.clear_zone_override
data:
  entity_id: climate.multizone_thermostat_living
```

---

### `multizone_thermostat.set_preset_temperature`
Updates target setpoint for a specific preset in memory:

```yaml
service: multizone_thermostat.set_preset_temperature
data:
  entity_id: climate.multizone_thermostat_bedroom
  preset: comfort
  temperature: 20.5
```

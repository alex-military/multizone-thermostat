# Versioning Rules

For this specific project (Multizone Thermostat), follow this versioning scheme (`vX.Y.Z`):
- `X` = Roadmap Phase Number (e.g., `2` for Phase 2, `3` for Phase 3). Increment this ONLY when passing from one phase to the next.
- `Y` = Feature updates. Increment this every time a new feature or significant element is added relative to the current phase.
- `Z` = Minor updates. Increment this only for minor tweaks, bug fixes, and small adjustments.
